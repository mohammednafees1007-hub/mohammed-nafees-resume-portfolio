# Company-specific résumés

This folder is reserved for future requested company-specific versions. No tailored résumé is currently maintained here.

Use `<Company>/<Role>/PDF/`, `<Company>/<Role>/DOCX/` and `<Company>/<Role>/sources/` when a tailored version is requested. Add a README with the target role, source versions and update date. Use both canonical versions in `Resume/`: the comprehensive version supplies evidence and the general one-page version supplies the concise layout. Change copied generator output paths before running; do not overwrite the two canonical documents. Tailoring, PDF export, checks and application submission are not automatic.
